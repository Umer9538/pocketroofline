PocketRoofline · station 01 · iPhone 13 (A15 Bionic)

LLM inference measured on a phone, not an edge board.

RooflineBench characterised on-device inference across desktop GPUs, an M1 Pro, a Jetson and a Raspberry Pi — no phones. This extends the same roofline methodology to smartphone silicon, with every repeat retained, thermal state recorded, and the matrix re-run on every OS and runtime update.

38%

Peak decode (42.8 tok/s, short prompts) overstates sustained decode (30.9 tok/s, after 5 consecutive long generations) by this much. Quoted phone-inference numbers are peak numbers.

Stated limits

This session began at thermal state fair, not nominal — the ten-minute ambient cooldown of METHODOLOGY §5 was not achieved — so these are warm-start figures and are labelled as such. A cold-start session is owed and will be published beside this one rather than replacing it.

The declining regime's mean is not a steady-state figure: the series is non-stationary by construction, so the throttling curve is the result and its average would be a fiction. Repeats whose thermal state changed mid-run are excluded from aggregates, flagged, and still shown above.
